## 0.0.2

### Patch Changes

## 0.1.0

### Minor Changes

- Initial release of `@baasix/lexical` rich text editor plugin
- Forked from [facebook/lexical](https://github.com/facebook/lexical) playground at v0.41.0
- Adapted as a standalone React component with Baasix SDK integration
- Includes 40+ editor plugins: toolbar, tables, images, code blocks, equations, embeds, and more
- HTML bidirectional sync with debounced onChange
- Fullscreen mode, read-only mode, and character limit support
